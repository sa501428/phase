# Local somatic assembly and phasing: algorithm notes

Reviewed November 10, 2026. The target is an explicitly selected gene, exon, or small genomic interval in one indexed short-read BAM. It is an exploratory view of a somatic mixture with an unknown number of local sequence haplotypes and potentially unequal abundances. It is not whole-genome reconstruction or a diploid germline phaser.

The implementation uses original JavaScript informed by the methods below. It is not a port of these programs, does not reproduce their complete statistical models, and has not been benchmarked against them. Their published accuracy claims do not apply to Phase.

## Methods considered

| Method and primary source | Relevant idea | Decision for Phase |
| --- | --- | --- |
| [Lancet — Narzisi et al., 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6123722/) | Local colored de Bruijn graphs for somatic SNVs/indels; strand-aware nodes, read provenance, overlapping-mate count correction, repeat-aware k selection. | Construct a bounded local graph, retain fragment provenance, fold reverse complements and count each physical fragment once. Keep configurable k and unresolved repeat topology. Reference annotates existing nodes rather than supplying sequence. No tumor/normal classifier, automatic k optimization, Lancet path enumeration or calibrated variant scoring is implemented. |
| [SAVAGE — Baaijens et al., 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5411778/) | Overlap graphs retain co-occurring mutations; conservative overlaps, paired-end constraints and clique-based assembly protect individual strain sequences. | Keep actual read traversals and paired-fragment allele co-observations alongside the compact sequence graph. Never count all combinatorial graph walks as clones. A contradictory callable SNP vetoes grouping. This is not SAVAGE's overlap graph, clique enumeration, probabilistic overlap scoring, error correction or iterative contig extension. |
| [WhatsHap polyphase — Schrinner et al., 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7504856/) | Separate read clustering from haplotype threading; locally identical haplotypes can share a cluster; uncertainty cuts help prevent unjustified long phase connections. Its threading stage uses a specified ploidy. | Preserve shared/ambiguous fragments; do not infer one cellular clone per identical local sequence. Require the selected minimum number of noncontradictory fragments before linking two bubble features into an evidence block. Do not adopt fixed-ploidy threading, equal haplotype abundance assumptions or their genotype model. Phase's simple support cut is not their statistical block-cut algorithm. |
| [Haploflow — Fritz et al., 2021](https://link.springer.com/article/10.1186/s13059-021-02426-8) | Compact unitig graphs and coverage-guided flow decomposition resolve viral mixtures; ambiguous continuation can terminate a contig. | Use compact sequence segments and expose branch support. Preserve unresolved continuation. Do not use coverage alone to connect alleles or estimate cellular clone abundance: targeted exome/amplicon coverage, copy number and PCR effects make that assumption unsafe here. No fattest-path/flow-subtraction algorithm is implemented. |

The viral methods are useful algorithmic analogies for mixtures, not evidence that viral abundance models transfer to cancer. WhatsHap polyphase likewise informs uncertainty handling without supplying an unknown-ploidy somatic model.

## Implemented algorithm

1. **Select the target before reconstruction.** Read only the selected interval through BAI/CSI, with bounded indexed retrieval of named same-contig mates. Do not scan the BAM or assemble unrelated mate regions. Retain fetched records for paired evidence. Crop assembly sequence to the selected aligned coordinates; include insertions/soft clips anchored inside the target.
2. **Construct from observed sequence.** Build a strand-symmetric de Bruijn graph using quality-eligible consecutive k-mers from the reads. Record distinct fragment support on nodes and observed adjacency edges. Split at unavailable/low-quality bases. The optional reference neither creates nodes nor adds edges.
3. **Compact without losing branches.** Collapse maximal nonbranching chains into unitigs; fold the reverse-complement representation for display. Preserve cycles, weak branches and their supporting records. A unitig's support label is the minimum distinct-fragment support among its k-mers; it is not copy number.
4. **Resolve bounded, read-observed bubbles.** Search for nearby branch reconvergence. An allele sequence must be observed between the two anchors on an actual read. Other fragments may identify an allele through diagnostic k-mers unique among the observed bubble alleles. Complex/repetitive or insufficiently spanned structures remain unresolved. Diagnostic k-mers are not guaranteed unique across the whole genome.
5. **Thread physical fragments.** Pair by query name within sample/read group. Overlapping ends do not provide independent votes. Internally contradictory fragments remain explicit. Link bubble features only with sufficient shared fragment support; preserve weak links separately.
6. **Suggest compatible local patterns.** Process informative fragments from most to least observed evidence, retaining unknown positions. Group only compatible feature calls with a shared observed feature and no contrary callable aligned SNP anywhere in the target, including singleton SNPs outside the bubble list. Keep multiple-compatible fragments shared, and keep weak patterns separate. This conservative greedy heuristic is order dependent in difficult partial-coverage cases; it does not optimize a global likelihood or prove a minimal haplotype cover.
7. **Annotate and inspect.** When available, map unique reference anchors to bubbles and highlight allele differences. Show per-allele callable-fragment fractions and per-pattern exclusive fragment shares with their denominators. Read rows use original CIGAR geometry; graph layout is topological, not a genomic coordinate ruler.
8. **Report physical phase conservatively.** Count jointly observed ALT/ALT, ALT/REF, REF/ALT and REF/REF fragments for requested variants. Cis is direct linkage evidence. Separate patterns do not establish trans in an unrestricted mixture. Similarity among local patterns is descriptive, not a tumor phylogeny.

Graph export follows the [GFA 1 specification](https://gfa-spec.github.io/GFA-spec/GFA1.html): oriented sequence segments and observed adjacency links, with k−1 overlap. Segment `FC` is the union of traversing fragments; custom `ms` records minimum k-mer support. Export contains assembled case sequences and happens only on explicit user action.

## Evidence and remaining uncertainty

Synthetic tests include ten nested/sibling somatic sequence lineages at 3–36 fragments per lineage, paired ends, two founder mutation sets, unequal allele fractions, conserved founder-only fragments, disconnected blocks, short insertion/deletion alleles, weak bridges, repeats, unavailable SEQ and contradictory SNPs. Ground truth lineage labels and counts never enter assembly. Tests verify recovered local patterns and physical linkage, not an inferred evolutionary history.

The ten-lineage example is a controlled demonstration, not a validated detection limit. One locus may contain fewer distinguishable haplotypes than actual cell clones; one cell clone may contain multiple homolog/copy-number sequences. Repeats, sparse linkage, mapping ambiguity and errors may produce extra weak paths or hide real lineages. The graph shows that uncertainty instead of forcing a fixed number of clones. Large rearrangements use local split/mate clues; remote breakpoint sequence and genome-wide clone identities are outside scope.
